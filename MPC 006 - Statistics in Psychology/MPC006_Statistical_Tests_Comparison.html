🔍 Comparison Table

Test What It Measures Type Symbol Formula Steps (incl. Critical Value & Interpretation) Noteworthy Points
One-Way ANOVA Variance / Differences between means of 3+ independent groups (k > 2). Compares between-group to within-group variance. Parametric F
F = MSB / MSW
  1. 1. State H₀ & H₁
  2. 2. Calculate SSB, SSW, SST
  3. 3. Calculate MSB & MSW
  4. 4. Compute F-ratio
  5. 5. Compare with critical F-value (df = k–1, N–k) & interpret
 Assumes: Normal distribution, Homogeneity of variance, Interval/Ratio data, Independent samples. Developed by Sir Ronald Fisher.
t-Test (Independent) Differences between means of 2 independent groups. Determines if two sample means come from same population. Parametric t
t = (X̄₁ – X̄₂) / √(s²₁/n₁ + s²₂/n₂)
  1. 1. State H₀ & H₁
  2. 2. Compute means & variances
  3. 3. Calculate t-statistic
  4. 4. Determine df = n₁ + n₂ – 2
  5. 5. Compare with critical t-value & interpret
 Assumes: Normal distribution, Homogeneity of variance, Interval/Ratio data. Requires >30 per group.
Mann-Whitney U Test Degree of separation / overlap between 2 independent groups. Compares medians/ranks. Tests if samples come from identical populations. Non-Parametric U
U = N₁N₂ + [N₁(N₁+1)/2] – ΣR₁
U' = N₁N₂ + [N₂(N₂+1)/2] – ΣR₂
  1. 1. Rank all data combined
  2. 2. Sum ranks for each group
  3. 3. Calculate U & U'
  4. 4. Use smaller U value
  5. 5. Compare with critical table value (Table H)
  6. 6. Interpret result
 Equivalent to t-test for independent samples. Used when: Ordinal/ranks, Non-normal, Small sample, Unequal variances. Power ~95% of t-test.
Wilcoxon Matched-Pair Differences between 2 dependent/correlated groups (repeated measures or matched pairs). Compares median differences. Non-Parametric T
T = smaller of (ΣR⁺ , ΣR⁻)
  1. 1. Compute difference scores (D)
  2. 2. Rank absolute differences
  3. 3. Sum ranks of positive & negative differences
  4. 4. T = smaller sum
  5. 5. Compare with critical table value (Table J)
 Equivalent to paired t-test. Ranks difference scores, NOT original scores. Difference scores of 0 eliminated. Assumes symmetric distribution of difference scores.
Kruskal-Wallis ANOVA Differences between medians of 3+ independent groups. Extension of Mann-Whitney U. Non-Parametric H
H = [12/N(N+1)] · Σ[(ΣR)²/n] – 3(N+1)
  1. 1. Rank all data combined
  2. 2. Sum ranks for each group
  3. 3. Calculate H-statistic
  4. 4. Compare with critical value (Table H or χ² with df = k–1)
  5. 5. Interpret
 Equivalent to One-Way ANOVA. When k=2, equivalent to Mann-Whitney U. Uses chi-square approximation for N > 20.
Pearson Correlation (r) Strength & direction of linear relationship between 2 continuous variables. Parametric r
r = Σ[(X–X̄)(Y–Ȳ)] / √[Σ(X–X̄)² · Σ(Y–Ȳ)²]
  1. 1. Create scatter plot
  2. 2. Calculate r-value
  3. 3. Determine df = n–2
  4. 4. Compare with critical r-value
  5. 5. Interpret strength & direction
 Assumes: Normal distribution, Interval/Ratio data, Linear relationship, Homoscedasticity. Ranges from -1 to +1.
Spearman Rho (ρ) Strength & direction of monotonic relationship between 2 ranked/ordinal variables. Non-Parametric ρ
ρ = 1 – [6Σd² / n(n²–1)]
  1. 1. Rank both variables
  2. 2. Compute difference (d) for each pair
  3. 3. Square differences (d²)
  4. 4. Calculate ρ
  5. 5. Compare with critical table value
 Equivalent to Pearson r for ranked data. Efficiency of 91% vs Pearson r. Interprets monotonic relationships. Less sensitive to outliers.
Kendall's Tau (τ) Strength & direction of association between 2 ranked variables. Measures concordant vs discordant pairs. Non-Parametric τ
τ = 2S / [N(N–1)]
S = concordant – discordant pairs
  1. 1. Rank both variables
  2. 2. Rearrange X ranks in natural order
  3. 3. Observe Y ranks
  4. 4. Count concordant (+) & discordant (–) pairs
  5. 5. Compute S and τ
  6. 6. Compare with critical table value
 Different underlying scale than Spearman Rho. Both have 91% efficiency. Formula with ties: τ = 2S / √[N(N–1)–Tₓ][N(N–1)–Tᵧ]
Chi-Square Test Association / Independence between 2 categorical variables (or Goodness-of-Fit for one variable). Non-Parametric χ²
χ² = Σ[(O–E)² / E]
  1. 1. Create contingency table
  2. 2. Calculate expected frequencies (E = RT × CT / N)
  3. 3. Apply formula (O–E)²/E for each cell
  4. 4. Sum to get χ² value
  5. 5. Determine df = (r–1)(c–1)
  6. 6. Compare with critical χ² table value
 Assumes: Categorical/nominal data, Independent observations, Expected frequency ≥5 per cell. Two functions: Goodness-of-Fit & Test of Independence.
Regression Equation Prediction of one variable (Y) from another (X). Measures relationship and allows forecasting. Parametric Ŷ = a + bX
b = Σ[(X–X̄)(Y–Ȳ)] / Σ(X–X̄)²
a = Ȳ – bX̄
  1. 1. Calculate means (X̄, Ȳ)
  2. 2. Compute slope (b)
  3. 3. Compute intercept (a)
  4. 4. Form regression equation
  5. 5. Calculate R²
  6. 6. Test significance (using F or t-test)
 Assumes: Linear relationship, Normal residuals, Homoscedasticity, Independent errors. R² explains proportion of variance accounted for. Allows prediction.

⚡ Power Efficiency Summary

  • Non-parametric tests have ~91–95% power efficiency compared to parametric counterparts when parametric assumptions are met.
  • Non-parametric tests are often more powerful when parametric assumptions are violated (Blair et al., 1985).

❌ Five Key Misconceptions About Non-Parametric Tests

  1. Misconception: Non-parametric tests are less powerful.
    ✅ Fact: They are often equally or more powerful when assumptions are violated.
  2. Misconception: They are only for small samples.
    ✅ Fact: They can be used with any sample size.
  3. Misconception: They are restricted in application.
    ✅ Fact: There are non-parametric equivalents for almost every parametric test.
  4. Misconception: They throw away information.
    ✅ Fact: Ranks preserve order information and reduce outlier impact.
  5. Misconception: Peer reviewers may not accept them.
    ✅ Fact: They are widely accepted and recommended in psychological research.
